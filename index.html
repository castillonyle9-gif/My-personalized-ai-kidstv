Upload files to your repo

          In your new repo on GitHub:

          • Click Add file → Upload files

          • Upload agent.js into a folder called scripts/ (type scripts/agent.js in the path)

          • Upload package.json to the root

          • For the workflow: go into .github/workflows/ folder (create it) and upload agent.yml

          • Click Commit changes

Add each one as a separate secret. Name must match exactly (e.g. GEMINI_KEY_A, YT_REFRESH_TOKEN, etc.)

      


      

        

          
5

          
Get YouTube Refresh Token (one-time)
Run get_token.js once on your computer to authorize your channel

        

        

          Prerequisites: Node.js installed on your computer (nodejs.org → download → install).


          1. Download get_token.js from Step 2 above

          2. Open Terminal / Command Prompt in the same folder

          3. Run: node get_token.js

          4. It prints a URL → open it in your browser → authorize with your YouTube channel account

          5. Paste the code back into the terminal

          6. Copy the refresh_token it shows → add it as GitHub Secret YT_REFRESH_TOKEN

          7. Also save it in the YouTube Settings page here
        

      


    


    

      ✅ Once set up: GitHub Actions runs your agent automatically at 10AM, 3PM, and 7PM UAE time every day. You only use this app to generate content and trigger uploads. No maintenance needed.
