Complete setup guide
1
Fork / create the GitHub repo
Go to github.com → New repository → name it kidstv-agent → set to Public → create. Then upload all the files from this project (index.html, .github/workflows/agent.yml, scripts/agent.js, package.json).
2
Enable GitHub Pages
In your repo → Settings → Pages → Source: Deploy from branch → Branch: main → folder: / (root) → Save. Your site will be live at https://YOUR_USERNAME.github.io/kidstv-agent in ~2 minutes.
3
Get YouTube OAuth credentials
Go to console.cloud.google.com → New Project → Enable "YouTube Data API v3" → Credentials → Create OAuth 2.0 Client ID (Desktop app) → Download JSON. Run node scripts/get_token.js locally once to get your refresh token. Never share this.
4
Add secrets to GitHub
Repo → Settings → Secrets and variables → Actions → New secret. Add each key:

GEMINI_KEY_A · GEMINI_KEY_B · GEMINI_KEY_C
VID_KEY_1 · VID_KEY_2 · VID_KEY_3
YT_CLIENT_ID · YT_CLIENT_SECRET · YT_REFRESH_TOKEN
5
How queueing works (offline-safe)
When you add a topic on the website, it saves to queue.json in your repo via the GitHub API (no server needed). GitHub Actions runs at 06:00, 11:00, and 15:00 UTC daily, reads the queue, generates scripts with Gemini, creates a video prompt, and posts to YouTube. You can also trigger it manually from the Queue tab.
6
Commit the workflow file
The file .github/workflows/agent.yml is included in the download. Just push it to your repo and GitHub will automatically run it on schedule. Free for public repos (2,000 minutes/month on free plan — more than enough for 3 videos/day).
